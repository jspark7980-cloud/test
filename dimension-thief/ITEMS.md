# 차원 도둑 — 아이템 목록

> 표기: **[제안]** = 원 설계에 없어서 Claude가 정한 해석·값.
> 실제 데이터는 E단계에서 `data/items.js`로 옮긴다. 수치(가격·확률)는 `data/config.js`.

## 공통 규칙
- 장착 칸: 무기·방어구·장신구 각 1칸(도둑·동료 모두)
- 종류: 장비 / 소모품(전투 중 1회) / 전리품(로비 판매 전용)
- 등급: 일반 · 희귀 · 영웅 · 전설
- 상점 가격: 30 / 80 / 200 / 500 코인
- 상점 등장 확률(상점 레벨 1): 60 / 28 / 10 / 2 %
- 가방 기본 8칸, 안전 주머니 기본 1칸(최대 3칸)

## 무기
| 이름 | 등급 | 효과 | 구현 메모 |
|---|---|---|---|
| 녹슨 단검 | 일반 | 공격 피해 +1 | 피해 줄 때 +1 |
| 소매치기 칼 | 일반 | 슬쩍 시 대상에게 피해 3 | 슬쩍 후 대상 피해 |
| 쌍단검 | 희귀 | 매 턴 첫 공격 카드 2회 발동 | 카드 사용 시, 턴당 1회 |
| 독 바른 칼 | 희귀 | 공격마다 독 1 | 공격 카드로 피해 줄 때 대상 독+1 |
| 차원 절단기 | 영웅 | 다른 차원 출신 적에게 피해 +30% | 대상 출신 ≠ 현재 차원 |
| 그림자 비수 | 영웅 | 처치 시 에너지 +1 | 처치 시 |
| 시간 도둑의 낫 | 전설 | 강탈 조건 25% → 40% | 강탈 판정값 변경 |
| 만능 열쇠검 | 전설 | 슬쩍한 카드 비용 0 | 슬쩍한 카드에 비용 0 표시 |

- **[제안]** 동료가 장착하면 "공격 카드"는 동료가 쓰는 공격으로 해석. 슬쩍·강탈 관련 무기(소매치기 칼, 시간 도둑의 낫, 만능 열쇠검)는 도둑만 효과 있음.

- **[제안]** 위조 신분증·차원 안정제·귀환 두루마리는 맵 화면에서도 사용 가능.
