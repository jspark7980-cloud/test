# 몬스터 연구소 — 몬스터·특성·합성표

> **[제안]** = 원 설계에 없어서 Claude가 정한 값. 이름·계열·성향·특성 목록은 원 설계 그대로다.
> 진화 레벨·합성 값·출현 지역은 전부 **[제안]**이다. 종족값과 배우는 기술은 1단계에서 표로 제안한다.

**[제안] 합성 값 배치 원칙**
- 1단계 8~30, 2단계(3단계 계열의 중간) 40~50, 2단계 계열 최종 54~64, 희귀 66~76, 3단계 80~90, 합성 전용종 91~96, 전설 97~99, 숨겨진 몬스터 100.
- 값이 겹치지 않게 2씩 띄웠다(규칙 ③에서 동률이 거의 안 나오게).
- 희귀종은 단계 2와 3 사이 값이라, 2단계 + 3단계 몬스터를 합성하면 희귀종이 나올 수 있다(희귀종을 얻는 두 번째 길).

**[제안] 성향 → 고유 능력 해석**(1단계에서 수치 확정)
| 성향 | 해석 |
|---|---|
| 화상 / 마비 / 수면 / 독 | 그 상태 이상을 거는 기술을 일찍 배운다 |
| 반격(해일 계열) | 공격받으면 받은 피해의 20%를 되돌림 |
| 독 + 회복(늪개구리) | 독 기술과 자기 회복 기술을 함께 배운다 |
| 아군 공격 버프(촛불요정) | 등장 시 파티 전원 공격 +10%(전투 동안, 교체돼도 유지) |
| 회피 상승(해무가오리) | 회피를 올리는 기술 + 기본 회피 10% |
| 체력 흡수(꽃잎나방) | 준 피해의 50%를 회복하는 기술 |
| 접촉 반격(방전해파리) | 공격받으면 20% 확률로 상대 마비 |
| 피해 흡수(달팽이 계열) | 받는 피해 −15% |
| 빠른 바위(화석박쥐) | 바위 속성인데 속도 종족값이 높음 |
| 치명타(고양이 계열) | 기본 치명타 +10% |
| 기술 봉인(안개 계열) | 상대가 마지막에 쓴 기술을 2턴 봉인 |
| 상대 기술 복사(거울도깨비) | 상대가 마지막에 쓴 기술을 이번 턴 그대로 사용 |

## 4. 특성

모든 개체가 3개를 가지고 태어나고, 합성 돌연변이로 4번째 칸이 생긴다(최대 4칸). 낮은 등급일 확률이 높다(`DESIGN.md` 9.2). 테두리: 전설 무지개 / 금 / 은 / 동 / 나쁨 빨강.

| 등급 | 특성 | 효과 |
|---|---|---|
| 전설 | 전설의 혈통 | 공격·방어 +20% |
| 전설 | 시간 감각 | 항상 선공 |
| 전설 | 불사조의 심장 | 전투당 1회, 치명적인 피해를 체력 1로 버팀 |
| 금 | 맹공 | 공격 +15% |
| 금 | 철벽 | 방어 +15% |
| 금 | 신속 | 속도 +15% |
| 금 | 흡혈 | 준 피해의 10% 회복 |
| 금 | 상성 파괴자 | 불리 상성 감소 무시 |
| 은 | 투지 | 체력 30% 이하일 때 공격 +20% |
| 은 | 면역 | 상태 이상에 걸릴 확률 −50% |
| 은 | 행운아 | 치명타 +10% |
| 은 | 재생 | 매 턴 체력 3% 회복 |
| 은 | 속성 강화 | 같은 속성 기술 +10% |
| 동 | 근력 | 공격 +5% |
| 동 | 단단함 | 방어 +5% |
| 동 | 날렵함 | 속도 +5% |
| 동 | 대식가 | 회복 아이템 효과 +20% |
| 동 | 부지런함 | 경험치 +10% |
| 나쁨 | 겁쟁이 | 체력 50% 이하일 때 공격 −20% |
| 나쁨 | 게으름 | 10% 확률로 행동하지 않음 |
| 나쁨 | 허약 | 방어 −10% |
| 나쁨 | 불운 | 상대의 치명타 확률 +10% |

**[제안] 해석**
- 시간 감각끼리 만나면 속도 비교.
- "상성 파괴자"는 내가 공격할 때 ×0.67을 ×1로 바꾼다(방어할 때는 그대로).
- "불운"의 피치명타 = 나를 공격하는 상대의 치명타 확률 +10%.
- 퍼센트 효과는 같은 능력치끼리 더한다(맹공 15% + 근력 5% = 공격 +20%).
